## 核心判断

当前项目已经具备较完整的软件与机器人端雏形：Web、小程序、Spring Boot 后端、树莓派端、健康数据、事件提醒、WebRTC、远程遥控、AI 陪伴、硬件兜底模拟器等。

西门子杯的关键不是重新发明项目，而是把项目改写成“工程化、可制造、可验证、可商业化”的智能制造产品研发方案。评分表非常重视技术方案严谨性、三维模型、原型机现场验证、制造与品质控制、市场策略和 ESG。

已按团队确认修正：自由探索方向不强制使用西门子控制器。当前真实架构可以继续以树莓派边缘端、STM32/Arduino 类下位机、Spring Boot 后端、Web/小程序为主线。西门子相关内容只作为可选的工业自动化、工程管理或制造验证增强，不再作为合规前提。

已找到并入库可编辑三维模型源文件：原始目录为 `/Users/zhangchenxi/Desktop/西门子规划/可编辑瓦力`，仓库整理目录为 [`doc/三维建模资料`](../三维建模资料/README.md)，桌面同步目录为 `/Users/zhangchenxi/Desktop/西门子规划/三维建模资料`。目录中包含 `.SLDASM`、`.SLDPRT`、`.STEP`、`.3mf` 等 163 个源文件，后续重点是导出模型截图、爆炸图、BOM 和装配说明。

备赛时间已按团队反馈更新：比赛约在 2026-07-15 左右，因此取消原 8 周节奏，改为 2026-06-08 至 2026-07-12 的 5 周冲刺；2026-07-10 前建议形成可提交压缩包，2026-07-13 后进入赛前冻结窗口。

## 推荐比赛角色

比赛要求队员固定角色，专家针对某角色提问时只有该角色可以回答。建议：

| 队员 | 比赛角色 | 主要回答范围 |
| --- | --- | --- |
| 王姿元 | 产品经理 | 市场分析、用户需求、产品功能、商业模式、ESG、应用证明 |
| 张晨曦 | 研发工程师 | 软件架构、AI/视频/数据链路、机器人控制链路、接口与部署、测试数据 |
| 黄金 | 制造工程师 | 原型机结构、电气连接、三维模型、BOM、生产制造、品质控制、现场硬件测试 |

## 最近优先事项

1. 继续确认分赛区正式提交截止日期、抽签日期和准确比赛日期；当前规划先按 2026-07-15 左右比赛执行。

3. 确认当前原型机真实可演示功能：移动、云台/摄像头、健康数据、事件提醒、WebRTC、AI、报警闭环等。
4. 把旧材料中的夸张或未落地技术口径改成可验证口径，尤其是 SLAM、YOLO、LoRA/DPO、星闪延迟、跌倒准确率、WebRTC 延迟等指标。
5. 按 [05-原型机测试表草案.md](05-原型机测试表草案.md) 在 2026-07-05 前完成一次全链路演示录像和现场测试记录。
