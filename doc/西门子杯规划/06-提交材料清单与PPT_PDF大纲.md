## 完整方案 PDF 大纲

建议 25-40 页正文 + 附录。不要直接搬旧 74 页 PDF，西门子杯更看工程严谨性。

### 0. 匿名封面

- 项目名称。
- 赛项方向。
- 不出现学校、姓名、联系方式、指导老师、标志。

### 1. 执行摘要

- 一句话定义产品。
- 核心用户与痛点。
- 三个创新点。
- 原型机完成状态。
- 当前样机真实架构与完成状态。

### 2. 需求来源与产品创意

- 居家养老安全、陪伴、远程照护断层。
- 用户画像：独居老人、异地子女、社区/养老机构。
- 产品核心价值：让老人低门槛获得安全守护，让子女远程“看得见、叫得醒、帮得上”。
- 与固定摄像头、智能音箱、普通陪护机器人的差异。

### 3. 系统总体方案

- 端-边-云架构图。
- 边缘端定位：树莓派负责摄像头、语音、NearLink 数据解析、WebRTC、Socket.IO、TTS、健康上传。
- 数据流：传感器 -> 树莓派/边缘端 -> 后端 -> Web/小程序。
- 控制流：Web/小程序 -> 后端 -> 树莓派 -> 下位机/执行器。
- 隐私流：授权、最小化采集、异常触发。

### 4. 技术方案与工程实现

按评分表“基本工作原理、控制程序、图纸设计、研发流程”组织。

必须包含：

- 机器人控制链路：Web 指令、后端机器人代理、树莓派 Socket.IO、串口下发、底盘/云台执行。
- 安全策略：停止指令、通信超时、异常状态记录、兜底演示。
- 后端接口：健康、事件、设备、机器人代理、AI 代理。
- Web/小程序功能：健康、视频、遥控、事件、AI。
- 树莓派端：摄像头、NearLink、WebRTC、Socket.IO、TTS、健康上传。
- 电气连接图、通信协议、接口摘要。

### 5. 原型机制作与测试

- 样机结构图和实物图。
- 原型机测试表摘要。
- 每项测试：方法、预期、实际、证据。
- 现场演示流程。
- 兜底预案：只作为稳定性保障，不替代真实硬件。

### 6. 制造可行性与品质控制

- 三维建模软件和源文件说明：源文件位于 `/Users/zhangchenxi/Desktop/西门子规划/可编辑瓦力`，包含 `.SLDASM/.SLDPRT/.STEP/.3mf`。
- 机械装配流程。
- 电气装配流程。
- BOM 与成本。
- 生产线质量控制：来料检验、装配检验、烧录测试、功能测试、老化测试、出厂测试。
- 可维护性：模块化替换、远程配置、日志诊断。

### 7. 市场策略

- 市场规模与政策：使用最新可引用数据。
- 需求分析：老人、子女、社区、养老机构。
- 竞品对比：固定摄像头、智能音箱、普通陪伴机器人、养老护理机器人。
- 定价策略：基础版、机构版、服务订阅。
- 盈利模式：硬件销售、设备维护、机构服务、数据看板/平台服务。
- 推广策略：社区试点、养老机构、线上渠道、合作伙伴。
- 知识产权与保护：软著、专利计划、算法/结构/外观保护。

### 8. ESG 与风险管理

- E：低功耗、待机策略、模块化维修、可回收材料。
- S：适老化、隐私保护、客户满意、无障碍交互。
- G：供应链替代、质量追溯、数据安全、AI 医疗风险边界、异常处置机制。

### 9. 发展规划

- 近期：完成真实功能测试数据、三维模型提交包、PPT/PDF 初版。
- 中期：社区/机构试点，完善报警和服务闭环。
- 长期：多设备协同、更多传感器、机构管理平台。

## 匿名合规检查

提交前逐项检查：

| 检查项 | 方法 |
| --- | --- |
| 文本身份信息 | 搜索学校名、学院名、队员名、老师名、手机号、邮箱、GitHub 用户名 |
| 图片身份信息 | 检查截图中的浏览器账号、桌面、文件路径、学校 logo、微信头像 |
| 视频身份信息 | 检查开头/结尾字幕、环境背景、旁白是否说出学校或姓名 |
| PDF 元数据 | 导出后检查作者、标题、公司等元数据 |
| GitHub 链接 | 初赛材料中一般不放公开仓库链接，避免暴露队伍身份 |
