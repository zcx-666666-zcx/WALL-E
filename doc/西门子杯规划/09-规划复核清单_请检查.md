## B. 当前规划重点

1. 不再做“西门子控制器强制改造”。
2. 优先把现有 Web -> 后端 -> 树莓派 -> 下位机/执行器链路跑稳、测清楚、录视频。
3. 从已入库三维模型导出整机图、爆炸图、底盘/履带图、头部/传感器图。
4. 旧材料中的 SLAM、YOLO、LoRA/DPO、星闪低延迟、跌倒准确率等指标，只有能重新测试留证的才写成“已实现指标”。
5. PPT/PDF 按评分表组织：产品创意、市场策略、技术方案、三维建模、应用证明、ESG、原型机测试、生产管理。
6. 8 周计划已取消；当前按 2026-06-08 至 2026-07-12 五周交付，2026-07-13 至 2026-07-15 冻结。
