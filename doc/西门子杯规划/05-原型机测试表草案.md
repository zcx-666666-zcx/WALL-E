## 单项测试细化

### T02 健康数据采集与刷新

功能说明：

- 系统采集心率、呼吸、温湿度、跌倒状态，并在 Web/小程序端展示。

测试方法：

1. 确认设备号为 `WALLE_1` 或当前真实设备 ID。
2. 启动树莓派端健康上传或真实星闪链路。
3. 打开 Web 健康页，等待 10 秒。
4. 记录最新值、刷新间隔和后端日志。

预期结果：

- 页面至少出现 4 类体征数据。
- 数据在 1-2 秒级刷新。
- 后端健康接口返回 `code=1`。

注意：

- 如果使用模拟器，测试结果必须标注“模拟器兜底测试”，不能作为真实星闪性能指标。

### T05 远程遥控底盘/云台

功能说明：

- 子女端通过 Web 控制台远程控制机器人移动、云台和音效/动画。

测试方法：

1. Web 选择绑定设备。
2. 进入遥控页，点击/拖动遥控控件。
3. 观察机器人动作、PLC 输出、树莓派 Socket.IO 日志。
4. 发送停止指令，确认机器人停止。

预期结果：

- 后端打印或记录 `cmd_motor`、`cmd_servo` 等指令。
- 机器人或控制器输出与指令一致。
- 停止/超时后没有持续移动。

### T06 西门子控制安全联锁

功能说明：

- 使用西门子控制器承接关键控制和安全逻辑，提升工程可靠性。

测试方法：

1. PLC 处于运行状态，Web 或树莓派发送运动使能。
2. 触发急停输入或通信超时条件。
3. 观察电机使能输出、报警输出、Web 状态。

预期结果：

- 急停或超时后，电机输出立即断开。
- 报警灯/蜂鸣器动作。
- 系统可复位，复位后才能再次运动。

需要补充：

- 具体 PLC 型号。
- IO 点表。
- 现场接线照片。
- TIA Portal 程序截图。
